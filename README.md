# 😊 Emotion Detection

> Detecting emotions in text with classic NLP

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![scikit-learn](https://img.shields.io/badge/scikit--learn-1f6feb?style=flat-square) ![Pandas](https://img.shields.io/badge/Pandas-1f6feb?style=flat-square)

## 📌 Overview
A text classification model that predicts the emotion behind a sentence using TF-IDF features and Logistic Regression.

## ✨ Features
- Text cleaning and preprocessing
- TF-IDF vectorization
- Logistic Regression classifier
- Predict emotion for custom input

## 🛠️ Tech Stack
Python, scikit-learn, Pandas

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python predict.py "I can't believe how great today was!"
```
